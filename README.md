# StockFlow

Sistema web para la gestión y trazabilidad de inventarios.

# Descripción

StockFlow es un sistema web de gestión y trazabilidad de inventario,
diseñado con enfoque multiempresa. Su propósito es centralizar el
control de productos, lotes, ubicaciones y movimientos de inventario,
manteniendo un historial de las operaciones realizadas.

El proyecto se plantea inicialmente a partir de un caso de referencia
de COMTUMAC y está diseñado con la posibilidad de adaptarse
posteriormente a diferentes empresas mediante un esquema de
licenciamiento.

# Objetivo

Desarrollar una solución tecnológica que permita gestionar de manera
organizada el inventario, controlar sus movimientos y facilitar la
consulta de información mediante reportes, indicadores y mecanismos
de trazabilidad.

## Funcionalidades principales

- Gestión de usuarios, roles y permisos.
- Gestión de productos y lotes.
- Control de inventario por ubicación.
- Registro de producción y transformación.
- Traslados de inventario.
- Gestión de distribuidores.
- Gestión de ferias y eventos.
- Registro de ventas.
- Registro de obsequios y consumo interno.
- Gestión de devoluciones.
- Conteos físicos y ajustes.
- Alertas de vencimiento y bajo inventario.
- Dashboard e indicadores.
- Reportes y exportación de información.
- Auditoría y trazabilidad de operaciones.
- Separación de información entre empresas.

## Alcance inicial

El proyecto se encuentra en fase de análisis y diseño. El alcance
inicial contempla el levantamiento de requisitos, definición de reglas
de negocio, modelado de casos de uso, diseño de la base de datos,
definición de arquitectura y posterior desarrollo del sistema.

para el análisis de los procesos de inventario. La solución se plantea
